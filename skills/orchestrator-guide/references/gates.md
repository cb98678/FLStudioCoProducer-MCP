# V1 gates: the human decides, never the agent

- The melody MIDI and the invariants file in a restyle (before rebuilding).
- The genre profile, tempo policy and target file choice when the spec sheet leaves them open.
- Any sound-design result ("does this growl work?") and any taste call ("too bright").
- The loudness-matched A/B before delivery.
- Promotion of anything into a real project (A3, human only).
- Reaching the iteration cap.

When unattended: write the pending decision and stop. Do not guess.
