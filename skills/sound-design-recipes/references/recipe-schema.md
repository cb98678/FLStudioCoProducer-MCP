# Recipe file (recipes/<name>.toml)

```toml
[meta]
name = "growl_mid_bass"
plugin = "the exact plugin name as FL shows it"
note = "what it is for, in the human's words"

[params]
"Cutoff" = 0.42       # parameter name exactly as list_plugin_params shows it, value 0 to 1

```

Nothing is shipped: parameter names depend on the plugins on the machine. Recipes are created with the human: propose, apply, listen, approve, save.
