# Before and after a change

Before:
- [ ] Phase and slice allow the tool.
- [ ] Open project is the sandbox copy (`ping_fl`).
- [ ] Current value read.
- [ ] Snapshot taken if the step is risky.

After:
- [ ] The tool returned `verified: true`.
- [ ] The new value is in the step's log line, with units.
- [ ] If the change affects sound, a later render and measure will confirm it; plan that step.
