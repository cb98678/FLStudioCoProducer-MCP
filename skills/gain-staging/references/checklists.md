# Gain staging checklist

- [ ] Snapshot taken before the first change.
- [ ] Audio playing while peaks are read.
- [ ] Sources first, buses next, master chain last.
- [ ] Each change small, verified, and logged with before and after values in dB.
- [ ] Master fader untouched unless the human asked.
- [ ] Final render measured: true peak and clipped sample count against the targets file.
- [ ] A short summary of per-track changes is ready for the human.
