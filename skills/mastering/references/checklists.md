# Mastering checklist

- [ ] Targets file loaded without blanks.
- [ ] Snapshot before the first change.
- [ ] Each check uses a render made after the last change.
- [ ] Loudness: integrated value vs target. True peak vs ceiling. Clipped samples vs maximum.
- [ ] Crest factor and loudness range still inside their ranges.
- [ ] Low end mono check done.
- [ ] A/B package built with matched loudness.
- [ ] Report written with before and after numbers.
- [ ] Human approval recorded with `record_decision`.
